# Hướng dẫn văn phong — Tiếng Việt (vi)

- **Xưng hô**: trung tính, lịch sự ("bạn"). Không đổ lỗi cho người dùng.
- **Thuật ngữ**: bản trình bày / tài liệu / bảng tính / biểu mẫu (theo Google).
- **Dấu câu**: không cần dấu chấm cuối nhãn UI; dấu ba chấm `...`.
- **Ngắn gọn**: trên nút/nhãn chọn từ ngắn mà vẫn rõ (ví dụ "Ẩn/Hiện"). Dễ hiểu là trên hết.
- **Không dịch**: Google / Gemini / OpenAI / Claude / API / LLM / RPD / RPM, tên mô hình, URL.
- **Ký tự giữ chỗ**: `{fileType} {engine} {count} {position} {status} {error} {model} {url} {suffix}` giữ nguyên.
