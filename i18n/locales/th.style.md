# แนวทางการเขียน — ภาษาไทย (th)

- **ระดับภาษา**: สุภาพเป็นกลาง (ไม่ใส่ครับ/ค่ะ ในป้ายกำกับ UI). ไม่โทษผู้ใช้.
- **คำศัพท์**: งานนำเสนอ / เอกสาร / สเปรดชีต / ฟอร์ม (ตามศัพท์ Google).
- **เว้นวรรค**: เว้นวรรครอบชื่อเฉพาะภาษาอังกฤษ (เช่น `ด้วย {engine} …`). ไม่ใส่จุดจบประโยค UI.
- **ความสูงบรรทัด**: ไทยมีวรรณยุกต์บน-ล่าง — line-height ตั้งไว้ 1.65 ใน registry อย่าลดต่ำกว่านี้.
- **ไม่แปล**: Google / Gemini / OpenAI / Claude / API / LLM / RPD / RPM, ชื่อโมเดล, URL.
- **ตัวยึด**: `{fileType} {engine} {count} {position} {status} {error} {model} {url} {suffix}` คงไว้เหมือนเดิม.
