# 日本語（ja）翻訳スタイルガイド

- **語調**：丁寧語（です・ます）。命令形ではなく「〜してください」。
- **用語**：スライド／ドキュメント／スプレッドシート／フォーム（Google 用語に合わせる）。
- **句読点**：全角 `。、（）「」`。省略記号は三点リーダ `…`。感嘆符 `！` は控えめに。
- **スペース**：和文と欧文の固有名詞の間に半角スペース（例：`{engine} で翻訳中`）。
- **翻訳しない**：Google / Gemini / OpenAI / Claude / API / LLM / RPD / RPM、モデル名、URL。
- **プレースホルダー**：`{fileType} {engine} {count} {position} {status} {error} {model} {url} {suffix}` はそのまま。
