# Guía de estilo — Español (es)

- **Registro**: tuteo ("tú"), neutro (evitar regionalismos). No culpar al usuario.
- **Términos**: presentación / documento / hoja de cálculo / formulario (términos de Google).
- **Puntuación**: signos de apertura `¿ ¡` cuando corresponda; comillas angulares « ».
- **Concisión**: en botones/insignias se prefiere la palabra más corta que se entienda
  (p. ej. "Guardar" en vez de "Guardar configuraciones"). Comprensión ante todo.
- **No traducir**: Google / Gemini / OpenAI / Claude / API / LLM / RPD / RPM, nombres de modelo, URL.
- **Marcadores**: `{fileType} {engine} {count} {position} {status} {error} {model} {url} {suffix}` intactos.
