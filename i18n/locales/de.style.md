# Stilrichtlinie — Deutsch (de)

- **Anrede**: Sie-Form. Den Nutzer nicht beschuldigen.
- **Begriffe**: Präsentation / Dokument / Tabelle / Formular (Google-Begriffe).
- **Kürze ist Pflicht**: Deutsch läuft 30–40 % länger. Auf Buttons/Badges das kürzeste
  klare Wort wählen — „Speichern" statt „Konfigurationen speichern", „Stoppen" statt
  „Übersetzung stoppen". Verständlichkeit vor Wörtlichkeit.
- **Nicht übersetzen**: Google / Gemini / OpenAI / Claude / API / LLM / RPD / RPM, Modellnamen, URLs.
- **Platzhalter**: `{fileType} {engine} {count} {position} {status} {error} {model} {url} {suffix}` unverändert.
