# Guide de style — Français (fr)

- **Registre** : vouvoiement ("vous"). Ne pas blâmer l'utilisateur.
- **Termes** : présentation / document / feuille de calcul / formulaire (termes Google).
- **Ponctuation** : espace insécable avant `: ; ! ?` (géré par la police) ; guillemets « ».
- **Concision** : sur les boutons/badges, choisir le mot le plus court et clair
  (p. ex. « Enregistrer »). La compréhension prime sur la littéralité.
- **Ne pas traduire** : Google / Gemini / OpenAI / Claude / API / LLM / RPD / RPM, noms de modèle, URL.
- **Marqueurs** : `{fileType} {engine} {count} {position} {status} {error} {model} {url} {suffix}` intacts.
