# 한국어(ko) 번역 스타일 가이드

- **어조**: 존댓말(합니다/하세요체). 사용자를 탓하지 않는 표현.
- **용어**: 프레젠테이션 / 문서 / 스프레드시트 / 설문지(Google 용어 기준).
- **문장부호**: 마침표 없이 끝내는 UI 관례 존중, 생략은 `…`. 조사 처리: `{engine}(으)로` 형태 유지.
- **띄어쓰기**: 고유명사와 한글 사이 한 칸(예: `Google Drive에서`).
- **번역 안 함**: Google / Gemini / OpenAI / Claude / API / LLM / RPD / RPM, 모델명, URL.
- **자리표시자**: `{fileType} {engine} {count} {position} {status} {error} {model} {url} {suffix}` 그대로 유지.
