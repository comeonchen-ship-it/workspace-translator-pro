Privacy Policy

Workspace Translator Pro  ·  Last updated: October 2026

🔒 We do not collect, store, or transmit any personal data to our own servers. This extension operates entirely within your browser using your own API credentials.

What Data Is Stored Locally

The following data is stored only in your browser's local storage (chrome.storage.local). It is not sent to us — we operate no servers:

  • API key and engine settings — the key you enter (Gemini, OpenAI, Claude or a custom endpoint), the model name and endpoint address. The key is sent only to the provider you selected, to authorize translation requests.
  • Translation preferences — tone, how names are handled, your specific terms (for all files and per file) and your custom instructions.
  • Translation cache — pairs of original and translated text from previous translations, so repeated text is not sent for translation again. It is limited in size; the oldest entries are removed automatically.
  • Translation history — Google Drive file IDs and titles of the copies you created.
  • Progress and debug logs — the state of running jobs (so an interrupted job can resume) and short technical logs of the latest translation.
  • Interface settings — interface language and display options.

What Data Is Processed

When you start a translation, the extension:

  • Reads the text of the file you are translating via the Google Workspace APIs (Slides, Docs, Sheets or Forms)
  • Sends that text — and your translation preferences, if any — to the translation service you selected (Google Gemini, OpenAI, Anthropic Claude, your custom endpoint, or Google Translate for the basic free option)
  • Writes the translated text into a copy of your file in Google Drive — your original is never modified

Third-Party Services

Depending on your settings, the text of the file you translate is sent to one of these services. Please review their privacy policies:

  • Google Gemini API
  • OpenAI API
  • Anthropic Claude API
  • Your custom endpoint (if you configured one)
  • Google Translate — used by the basic free translation option, which needs no API key

Google Account Access

When you translate for the first time, Google asks you to sign in and allow access to Drive, Slides, Docs, Sheets and Forms. With that permission the extension can:

  • Read the file you choose to translate and create a copy of it
  • Read and write the content of that copy
  • Check whether previously translated copies still exist in Drive (to keep the history list current)

The extension does not access any files other than those you translate and the copies it created. You can revoke access at any time in your Google Account permissions.

Browser Permissions

  • Notifications — to tell you when a translation has finished while the side panel is closed.
  • Scripting — only on Google Sheets pages, to read the name of the sheet tab you are viewing when you choose "only translate the current sheet". Nothing else on the page is read.
  • Optional site access — requested only if you add a custom translation endpoint, and only for that address.

No Analytics or Tracking

This extension does not include any analytics, telemetry, crash reporting, or user tracking of any kind. We do not operate any backend servers.

Data Retention

All locally stored data persists in your browser until you:

  • Clear the Translation History via the History panel
  • Uninstall the extension
  • Clear your browser's local storage

Changes to This Policy

If we make significant changes to this privacy policy, we will update the "Last updated" date above. We encourage you to review this page periodically.
