Chrome Extension

Privacy Policy

Workspace Translator Pro  ·  Last updated: June 2025

🔒 We do not collect, store, or transmit any personal data to our own servers. This extension operates entirely within your browser using your own API credentials.

What Data Is Stored Locally

The following data is stored only in your browser's local storage (chrome.storage.local) and never leaves your device:

  • Google OAuth Client ID — entered by you in Settings
  • LLM API Keys — entered by you (Gemini, OpenAI, Claude, or custom)
  • Selected Model Name — your preferred AI model
  • Translation History — Google Drive file IDs and document titles of your completed translations
  • Debug Logs — temporary logs for the current translation session, stored per-session and not accumulated over time

What Data Is Processed

When you initiate a translation, the extension does the following:

  • Reads your document's text content via Google Workspace APIs (Slides, Docs, Sheets, or Forms)
  • Sends that text to the LLM API you configured (Google Gemini, OpenAI, Anthropic Claude, or your custom endpoint) for translation
  • Writes the translated text back to a copy of your document on Google Drive — your original is never modified

Third-Party Services

Depending on your settings, your document text is sent to one of these external services for translation. Please review their privacy policies:

  • Google Gemini API
  • OpenAI API
  • Anthropic Claude API
  • Your custom endpoint (if configured by you)

The Free Google Translate engine uses Google's public translation service without requiring an API key.

Google Drive Access

This extension requests Google Drive access through your own OAuth credentials (Client ID). The extension can:

  • Create copies of documents you select for translation
  • Read and write content to those copies
  • Check whether previously translated files still exist in Drive (for History sync)

The extension does not access any files beyond those you explicitly initiate translation on.

No Analytics or Tracking

This extension does not include any analytics, telemetry, crash reporting, or user tracking of any kind. We do not operate any backend servers.

Data Retention

All locally stored data persists in your browser until you:

  • Clear the Translation History via the History panel
  • Uninstall the extension
  • Clear your browser's local storage

Changes to This Policy

If we make significant changes to this privacy policy, we will update the "Last updated" date above. We encourage you to review this page periodically.
